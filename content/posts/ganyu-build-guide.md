写这篇的原因是：每次有朋友入坑问「甘雨怎么练」，我都要重新讲一遍。干脆写成文档，以后直接甩链接。

## 一、定位与核心机制

甘雨是**冰元素弓箭手**，核心输出手段是二段蓄力的**霜华矢**——蓄力满后射出的箭矢在命中后会产生一次范围冰伤。

关键点在于：**二段蓄力的霜华矢，其伤害构成中「霜华绽发」占比很高**，这意味着：

- 攻击力、冰伤加成、暴击三件套依然有效
- 但单纯的「瞄准射击」增伤并不等价于全伤害增伤

## 二、武器选择

| 档位 | 武器 | 说明 |
| --- | --- | --- |
| 首选 | 阿莫斯之弓 | 蓄力流最优解，被动与机制完美契合 |
| 平替 | 若水 / 飞雷之弦振 | 泛用性强，若水更偏重击 |
| 四星 | 试作澹月 | 锻造即可，性价比极高 |
| 四星 | 破魔之弓 | 需要有意识控制能量 |
| 过渡 | 鸦羽弓 | 前期可用，不建议精炼 |

> 如果只有一把五星弓，优先给甘雨。她的武器收益曲线比大多数主 C 都陡。

## 三、圣遗物

**首选：冰风迷途的勇士（四件套）**

- 时之沙：攻击力%
- 空之杯：冰元素伤害加成
- 理之冠：暴击伤害

**副词条优先级：**

1. 暴击伤害 / 暴击率（按 1:2 配平）
2. 攻击力%
3. 元素精通（融化队显著加分）
4. 元素充能效率（够用即可）

下面是我自己用的词条目标配置，可以直接存成 JSON 当作检查清单：

```json
{
  "build": "ganyu-frost-arrow",

```

换算成区间就是：

```text
暴击率建议区间：50% ~ 70%
暴击伤害建议区间：180% ~ 240%
攻击力白值 + 绿值建议：2200+
```

## 四、天赋优先级

```text
普通攻击（流天射术）  >  元素爆发（降众天华）  >  元素战技（山泽麟迹）
```

元素战技的主要作用是**嘲讽与冰莲伤害**，输出占比不高，前期可以只点到 6 级。

## 五、主流配队

### 融化队（上限最高）

甘雨 + 香菱 + 班尼特 + 钟离

- 香菱提供持续挂火
- 班尼特提供攻击力与治疗
- 钟离提供护盾与减抗

### 永冻队（最舒适）

甘雨 + 莫娜 + 迪奥娜 + 万叶

- 冻结让瞄准变得毫无压力
- 适合手机端与手残党

### 双冰共鸣队

甘雨 + 申鹤 + 万叶 + 珊瑚宫心海

## 六、三个常见误区

1. **「甘雨必须满命才强」** —— 一命即可成型，命座提升平缓，零命也能打满深渊。
2. **「蓄力太慢所以没用」** —— 手机端确实吃力，但 PC 端熟练后二段蓄力约 1.5 秒，节奏完全够用。
3. **「暴击率堆到 80% 更稳」** —— 冰套四件套对冻结目标自带 20% 暴击率加成，盲目堆暴击会浪费词条。
